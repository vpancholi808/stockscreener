One number for every pair keeps the table small. Correlation is what diversification is made of: at 1.0 the frontier is a straight line and there is nothing to gain. Below −1/(n−1) no set of assets could produce the matrix, so the slider stops there.

The Sharpe column is constant: moving along the capital allocation line changes how much risk you carry, never how well you are paid for carrying it. That is Tobin's two-fund separation — the risky mix is the same for a cautious investor and an aggressive one, and only the cash weight differs.
